NSB Zone C Android PWA prototype

1. Upload the entire folder to an HTTPS static host approved by your company.
2. Open its HTTPS URL in Chrome on Android. Choose Add to Home Screen / Install app.
3. Allow microphone access; voice dictation support depends on Android Chrome speech recognition.
4. All data stays in the browser localStorage on that device. Export JSON backups regularly.
5. This is NOT a cloud synchronized service. No real notifications are sent. Meeting dictation is not background audio recording.
6. 102 equipment records are PROVISIONAL C-facility, >5t selections, NOT ownership-verified.
7. The KPI targets are proposed and require company approval.
